# The learner is unmarked in every text and female in every clip

2026-08-01, surfaced while the user reviewed office-gig's personas and chose to
keep the learner gender-unmarked.

The learner's card in every story says "default: unmarked adult, neutral
mid-range", and the Japanese backs it up — checked line by line across
office-gig: no わ, no かしら, no ぜ/ぞ, no 僕/俺, only the neutral 私. Any learner
can say every learner line as themselves.

The reference audio does not match that. The learner voice is `sohee` in the
taproom and again in office-gig's manifest; the café has no learner persona and
uses its staff voice instead. `sohee` reads female. So the learner is unmarked
in text and female in audio, in every story, on the clips the learner is
expected to **imitate directly**.

The user's decision was "stay unmarked" for the text. The audio side was not
decided and is app-wide rather than a property of any one story, so it is
recorded here rather than fixed inside office-gig.

Options, none chosen:

- Leave it. The clip is a model of the sentence, not a claim about the speaker.
- Cast a second learner reference voice and let the learner pick, which the
  manifest format already allows per line.
- Clone a neutral learner voice — blocked on a consented native Japanese
  reference clip, which this repo does not have, and the `datasets/` recordings
  must not be used because the learner imitates these clips.

Related: persona is required precisely so art and voice cannot disagree — see
[[2026-08-01-persona-versus-character-and-pass-e]]. This is the same class of
mismatch with the learner, who is never drawn, so it never triggers the
art/voice pairing check.
