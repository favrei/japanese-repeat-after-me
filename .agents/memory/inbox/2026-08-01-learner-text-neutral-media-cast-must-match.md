# Learner text stays neutral; learner media still needs one coherent cast

User correction on 2026-08-01: gender-neutral learner dialogue does **not**
mean the learner can be left uncast in media.

The learner's Japanese should remain playable and gender-neutral, but the app
still gives that learner a reference voice and generates the learner as a
visible character. Therefore the learner must have one explicit media persona,
and these must match:

- reference voice and its perceived gender/age/temperament;
- generated visual character and its perceived gender/age/temperament;
- declared learner persona and delivery direction;
- identity continuity wherever the learner appears across covers or scenes.

The text can remain unmarked even when the media casting is specific. Textual
neutrality is an accessibility/playability constraint; it is not permission
for voice and art to depict different people.
